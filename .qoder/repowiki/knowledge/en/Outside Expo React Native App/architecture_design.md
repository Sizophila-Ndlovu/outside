The root is a thin Expo app: `index.js` registers `App` via `registerRootComponent`, and `App.js` renders `<AppNavigator />` from `./src/navigation/AppNavigator`, which is the single composition root for all child modules (auth, live-event map, host dashboard, event detail popup). Runtime configuration lives in `eas.json` defining development, preview, and production build profiles with internal distribution and auto-incremented versions. The package manifest pins Expo 54 / React Native 0.81 and declares the shared runtime dependencies (Supabase, React Navigation, expo-location/image-picker/web-browser) that every child screen consumes.
