The module is organized by React Native feature layers under `src/`: `navigation/AppNavigator.js` is the single entry point that wraps screens in a `@react-navigation/native-stack` navigator and conditionally renders either auth screens (`Login`, `Register`) or authenticated screens (`Map`, `HostDashboard`) based on the current session from the shared `hooks/useAuth.js` hook. The `useAuth` hook subscribes to Supabase auth state changes via `supabase.auth.onAuthStateChange` and exposes `{ user, loading }`. `screens/` contains four presentational components — `LoginScreen`, `RegisterScreen`, `MapScreen`, and `HostDashboardScreen` — each directly importing `../../lib/supabase` for database/storage/auth calls and using Expo Location/ImagePicker where needed. `components/VibePopup.js` is a reusable bottom-sheet-style overlay consumed by `MapScreen` to display posts, handle check-ins, and toggle likes for a selected event. Dependency direction is one-way: screens depend on hooks and shared components; navigation depends on all screens and the auth hook; nothing imports navigation from screens, keeping routing centralized.
